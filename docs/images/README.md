# Artwork and presentation assets

The root README uses the owner-supplied DuskLight wordmark at
`assets/images/logo.png`. The matching supplied square icon is retained at
`assets/images/icon.png`. Small packaging inputs are `assets/3ds/icon-48.png`
and `assets/3ds/banner.png`. These are project presentation materials, not
extracted runtime game data, and are not assigned the code's CC0 dedication.
Game names and associated trademarks retain their owners' rights.

The wordmark is displayed unchanged, with its existing transparency and aspect
ratio. No gameplay screenshot or simulated hardware image is used to imply
physical validation. The Website and Discord buttons follow the owner's
existing Starwing, Zelda and MK64 repository presentation. Local SVG badges
state fixed facts and do not claim a passing CI result or released version.

When replacing a presentation image, retain the approved source identity,
record its origin and terms, preserve aspect ratio and inspect actual GitHub
rendering on desktop and a narrow viewport.
